# Wavecast (working title)

A proprietary, personal-use, OS-agnostic replacement for SAM Broadcaster PRO
(Spacial Audio Solutions) — a dual-deck radio automation and internet
streaming console. This directory holds the **design schematics only**; no
implementation exists yet.

SAM Broadcaster has had no updates since April 2025, licenses that were
sold as "lifetime" now require annual renewal, and the company changed
hands to ownership users describe as having gutted the product. Rather than
keep paying for a stalled product, this is the plan to build a personal
equivalent that runs natively on Windows, macOS, and Linux from one
codebase.

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — full system schematics:
  component diagram, signal-flow/mixer diagram, data model, playback
  sequence, tech stack rationale, and build phases.

`Wavecast` is a placeholder codename — rename freely, this is not tied to
any branding.
